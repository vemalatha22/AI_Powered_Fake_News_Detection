# AI-Powered Fake News Detection using NLP and Machine Learning

## Project Overview

This project demonstrates the application of Natural Language Processing (NLP) and Machine Learning techniques for detecting fake news articles.

The system preprocesses textual news data, converts it into numerical features using TF-IDF vectorization, and applies Logistic Regression to classify news articles as real or fake.

The project also includes model evaluation, cross-validation, feature importance analysis, inference pipeline creation, and model export for future deployment as a web application.

## Model Performance

The Logistic Regression model achieved strong classification performance with consistent cross-validation accuracy and effective ROC-AUC performance.

The evaluation results indicate that the model generalizes well on unseen news articles without significant overfitting.
